## What Went Well

- **Pure-logic-first architecture paid its promised dividend.** 3.1 shipped `ReaderEngine` + `SettingsModel` as host-testable logic with zero `WatchUi`/`Communications` imports; the drift-free `lastAdvance += duration` accumulator and catch-up cap were correct and *pinned* before a single pixel existed. Every later story built on a trusted engine.
- **The `DisplayStrategy` seam earned the whole architecture bet.** When on-device probes killed the activity-session screen-on mechanism mid-3.7, the swap to app-mode (delete `ActivitySessionStrategy`, drop the Fit permission, invert the LOW-mode policy) touched **only `display/`** — exactly AR11's "a gate-V1 failure swaps a module, not the architecture." ADR 0003 records it; the session path is git-preserved (`81978d6`) for the future "PaceTurner Active" listing.
- **On-device visual/input checks repeatedly caught what no host test could** — and the team trusted them over the simulator. Long-word fit took 3 hardware iterations (3.2); the context view was reimplemented from a raw `View` to a native `CustomMenu` after discrete-scroll felt wrong on the wrist (3.4); the WPM stepper's commit-UX was corrected from the wrist (3.8). The Epic-1 "simulator lies" scar became standing practice.
- **3-layer adversarial review was load-bearing, not ceremony.** It caught the durability-class bugs the simulator structurally cannot exercise — the empty-decode position-clobber and retry-storm (3.6), the wake-grace edge-vs-level arming bug found by all three layers (3.7). 8/8 PASS with real patches each time.
- **Seeded-mutation "red-check" became institutional discipline** from 3.1 on, and it worked: in 3.8 it exposed a *vacuous* test (mutating `RAMP_BEAT_MAX_MS` still passed 96/96 because the assertion compared against the mutated constant) → hardened to literal pins.
- **Strict-L3, "cast at the seam, never lower strictness" held every story** through a gauntlet of poly-type/nullability traps (`Storage.ValueType`, `ByteArray` vs `Array<Number>`, `String?.equals`, `BufferedBitmap` union narrowing).
- **`resume-never-lies` is hardware-proven** — carousel force-quit → relaunch lands on Paused at-or-before the last force-saved word (3.6, on-device PASS).
- **The deferred-work ledger stayed honest and forward-pointing.** Every masked-by-`CannedWordSource` failure mode was written down against its Epic-4 activation site rather than silently accepted.

## What Was Challenging

- **The Docker / matco tester harness was a persistent, product-irrelevant tax.** The stale-binary trap (`rm -f watch/bin/app.prg` — a failed compile silently re-runs the old `.prg`) originated in 3.1 and became a standing ritual; 3.3 lost ~8 min to the ENTRYPOINT `-c` swallow/hang; 3.4 hit two Docker daemons holding divergent cached `connectiq-tester` images (an old per-device API DB spuriously rejected a clean line) plus root-owned `.mir` cache. None of it was our code.
- **ACs authored before the hardware gate ran were wrong — and 3.7 was the sharp case.** The epics' "when the display dims → auto-pause" predated Gate V1's *passed-dim* verdict, which made dim-LOW the *normal* reading state; auto-pausing on LOW would have paused every session ~8–15 s in. Resolving it needed on-device control probes V1 never ran, a mid-story mechanism replacement, a Nerya-approved **ADR 0003**, and formal AC1/AC2 amendments. The biggest surprise of the epic.
- **Unicode tax followed us from the phone to the watch.** 3.2's central problem was the ORP pivot being a UTF-8 *byte* index while Monkey C `String` has no byte-slice — the fix routes through a real `ByteArray`. Same class of ambush that hit four of six Epic-2 stories.
- **Atkinson Hyperlegible BMFont was deferred, and deferred, and deferred.** Generating a CIQ BMFont is real asset tooling; the native-font ramp shipped behind a one-line `fontFor()` seam in 3.2 and stayed the escape hatch for 3.4 (context body) and 3.5 (chapter-title 700 weight). 3.8 formally notes its typography AC is satisfied *only* by that clause. A standing visual-fidelity debt.
- **Burn-in / chrome discipline was easy to violate** — three separate review catches (jitter recomputed-after-paint 3.2; readout stuck in FINISHED 3.3; `drawFinished` omitting jitter 3.5). The AMOLED rule is load-bearing and unforgiving.
- **The drift-free accumulator's catch-up burst rippled into every pause/resume feature.** 3.5 needed a new `pauseAtCurrent()` + `play()` re-anchor so a ~2 s chapter card wouldn't trigger a word-skipping burst; the same limitation reappears as deferred edges in 3.5, 3.6, and 3.7.
- **`CannedWordSource` masks a whole class of Epic-4 failure modes** — null/unbuffered records, empty `bookId`, `Long` position types, orphaned keys. A large, consistent bucket of findings is deferred forward to when the real chunked/BLE source lands.

## Key Insights

1. **The simulator lies about display modes, input routing, and the watchdog — hardware exposure must be deliberate.** Proven again story after story; the on-device check is a required gate, not a nicety.
2. **A spec written before the hardware gate can be wrong, and the seam architecture is what makes that survivable** — a hardware surprise swapped a module (3.7 → app-mode) instead of forcing a redesign.
3. **Adversarial review + mutation red-check are the durability safety net for code the simulator can't run.** Every durability bug this epic was caught there, not by the green test count.
