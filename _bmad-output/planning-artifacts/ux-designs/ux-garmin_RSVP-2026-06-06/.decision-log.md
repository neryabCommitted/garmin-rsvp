  - Brand image: "a dark page with one luminous word." Watch identity from scratch; phone inherits Material 3 dark seeded from pivot red.
  - Palette: true black + warm off-white ink + ONE chromatic (pivot red `#FF5349`, softened from Nano's pure red). No status colors anywhere.

  - Chrome discipline: progress/WPM visible ONLY when paused; playback screen shows nothing but the word + guides + phantoms.
  - Input map: START=pause/resume, UP/DOWN=WPM±, BACK=sentence rewind (bends Garmin convention; long-press=exit), MENU=settings, touch mirrors.
  - Two-stage pause interpreted as: SentenceEnd wind-down, second press = instant freeze. FR8 verbatim wins if it differs.
  - Added vs. precedent: 3-beat start ramp, explicit Finished screen w/ stats.
  - Sync conflict: max-word-index wins (vs. timestamped LWW) — re-reading is cheap, losing place is not.
  - Dim/AON fallback: auto-pause on dim; words never flow on an unreadable screen.
  - No book-detail screen on phone (library-row actions suffice); phone deliberately a "quiet librarian."
  - Default WPM 250 (no source guidance).
  - Open questions list carried in EXPERIENCE.md tail.
